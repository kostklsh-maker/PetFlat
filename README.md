# PetFlat

Мобильное приложение (Android и iOS) — центральная платформа сервисов для владельцев домашних животных.
У владельца есть цифровой профиль, к которому по ежемесячному тарифу подключаются сервисы:

| Сервис | Что умеет в MVP | Тариф |
|---|---|---|
| **FindYpet** | Лента объявлений «потерялся / найден», поиск и фильтр, объявление в один клик из профиля питомца, звонок и «поделиться» | Базовый (бесплатно) |
| **Больничная карта** | Аллергии, хронические болезни, прививки с датой следующей (напоминания на главной), визиты к ветеринару | Стандарт |
| **Клубная карта** | Карта с номером и баллами, магазины-партнёры с кешбэком | Стандарт |
| **Карта для гостиниц** | Кормление, прогулки, привычки, лекарства, экстренный контакт; отправка карты в мессенджер | Стандарт |
| **Грумеры** | Салоны, услуги и цены, запись на дату и время, отмена | Премиум |

Тарифы и цены (0 / 299 / 599 ₽ в месяц, лимиты питомцев) задаются в `src/data/catalog.ts`.

## Стек

- [Expo](https://expo.dev) SDK 57 + React Native, TypeScript
- Expo Router (файловая навигация, `src/app/`)
- AsyncStorage — данные хранятся на устройстве (бэкенда пока нет)

## Запуск

```bash
npm install
npx expo start          # QR-код → приложение Expo Go на телефоне (Android / iOS)
npx expo start --web    # быстрый просмотр в браузере
```

Проверки: `npm run typecheck`, `npm run lint`.

## Сборка для магазинов

Сборка идёт в облаке через EAS, без Xcode и Android Studio:

```bash
npx eas-cli@latest login
npx eas-cli@latest build --platform android   # .aab для Google Play
npx eas-cli@latest build --platform ios       # для App Store (нужен Apple Developer аккаунт)
```

Идентификаторы приложения: `com.petflat.app` (iOS и Android, `app.json`).

## Структура

```
src/
  app/                 экраны (Expo Router)
    (tabs)/            Главная, Питомцы, Сервисы, FindYpet, Профиль
    pet/               карточка и добавление питомца
    service/           medical, club, hotel, grooming
    findypet/          объявление и создание объявления
    plans.tsx          выбор тарифа
    welcome.tsx        создание профиля владельца
  components/          UI-компоненты, тема, PlanGate (доступ по тарифу)
  data/                типы, каталог тарифов/сервисов/партнёров, начальные данные
  store/AppStore.tsx   состояние приложения и сохранение на устройстве
```

## Что нужно для продакшена

- **Бэкенд и аккаунты**: вход по телефону (SMS), синхронизация профиля между устройствами. Без него объявления FindYpet видны только на одном устройстве.
- **Оплата подписок**: сейчас смена тарифа — заглушка (`src/app/plans.tsx`). Для цифровых подписок внутри приложения Apple и Google обычно требуют свои in-app покупки (например, через RevenueCat). Эквайринг вроде ЮKassa подходит для оплаты физических услуг (груминг, гостиница).
- **FindYpet**: фото питомца (`expo-image-picker`), карта и геолокация, push-уведомления пользователям поблизости.
- **Партнёры**: API или кабинет для клиник, зоомагазинов, грумеров и гостиниц (запись, начисление баллов, доступ к медкарте).
- **QR-код питомца** на ошейник: по скану открывается страница с контактами владельца.
