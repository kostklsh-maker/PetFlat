# PetFlat 🇮🇱

Мобильное приложение (Android и iOS) — центральная платформа сервисов для владельцев домашних животных в Израиле.
У владельца есть цифровой профиль, к которому по ежемесячному тарифу подключаются сервисы.

**Языки:** עברית (с RTL-интерфейсом), русский, английский. Выбираются на первом экране и в профиле; по умолчанию берётся язык телефона.
**Валюта:** шекель (₪), цены с НДС. **Даты:** ДД/ММ/ГГГГ. **Телефоны:** формат +972.

| Сервис | Что умеет в MVP | Тариф |
|---|---|---|
| **FindYpet** | Лента «потерялся / найден», поиск и фильтр, объявление в один клик из профиля питомца, звонок и «поделиться» | Базовый (бесплатно) |
| **Больничная карта** | Аллергии, хронические болезни, прививки с датой следующей (напоминания на главной; подсказка про обязательную ежегодную прививку от бешенства для собак), визиты к ветеринару | Стандарт |
| **Клубная карта** | Карта с номером и баллами, магазины-партнёры с кешбэком | Стандарт |
| **Карта для пансионов** | Кормление, прогулки, привычки, лекарства, экстренный контакт; отправка карты в мессенджер | Стандарт |
| **Грумеры** | Салоны, услуги и цены в ₪, запись на дату и время (салоны закрыты в субботу), отмена | Премиум |

Тарифы: **Базовый** — бесплатно, 1 питомец; **Стандарт** — ₪29.90/мес, до 3 питомцев; **Премиум** — ₪59.90/мес, до 10 питомцев.
Всё это задаётся в `src/data/catalog.ts`. Магазины и салоны в каталоге вымышленные — замените их реальными партнёрами.

У собак есть поле «лицензия муниципалитета» (רישיון להחזקת כלב) рядом с номером чипа.

## Стек

- [Expo](https://expo.dev) SDK 57 + React Native, TypeScript
- Expo Router (файловая навигация, `src/app/`)
- AsyncStorage — данные хранятся на устройстве (бэкенда пока нет)
- Локализация без сторонних библиотек: словари в `src/i18n/`, форматирование через `Intl`

## Локализация

- Тексты интерфейса: `src/i18n/ru.ts` (эталон), `en.ts`, `he.ts`. TypeScript не соберёт проект, если в каком-то языке не хватает ключа.
- Данные каталога (тарифы, сервисы, партнёры, салоны) хранят строку на всех трёх языках (`L10n`).
- В компонентах: `const { t, tr, price, date, age, join } = useT();`.
- Иврит: на iOS/Android при переключении на иврит или с иврита приложение перезапускается один раз, чтобы развернуть интерфейс справа налево (`I18nManager.forceRTL`). В вебе направление меняется сразу.
- Пользовательский контент (объявления, клички) не переводится — в ленте FindYpet объявления остаются на языке автора.

## Запуск

```bash
npm install
npx expo start          # QR-код → приложение Expo Go на телефоне (Android / iOS)
npx expo start --web    # быстрый просмотр в браузере
```

Проверки: `npm run typecheck`, `npm run lint`.

## Сборка для магазинов

```bash
npx eas-cli@latest login
npx eas-cli@latest build --platform android   # .aab для Google Play
npx eas-cli@latest build --platform ios       # для App Store (нужен Apple Developer аккаунт)
```

Идентификаторы приложения: `com.petflat.app` (iOS и Android, `app.json`).

## Структура

```
src/
  app/                 экраны (Expo Router)
    (tabs)/            Главная, Питомцы, Сервисы, FindYpet, Профиль

    service/           medical, club, hotel, grooming

    welcome.tsx        выбор языка и создание профиля владельца

  store/AppStore.tsx   состояние приложения и сохранение на устройстве
```

## Что нужно для продакшена

- **Бэкенд и аккаунты**: вход по телефону (SMS), синхронизация между устройствами. Без него объявления FindYpet видны только на одном устройстве.
- **Оплата подписок**: сейчас смена тарифа — заглушка (`src/app/plans.tsx`). Для цифровых подписок в приложении Apple и Google обычно требуют свои in-app покупки (например, через RevenueCat). Оплату физических услуг (груминг, пансион) можно принимать через израильских провайдеров — Tranzila, CardCom, Meshulam/Grow, PayPlus; стоит поддержать Bit.
- **Налоги и документы**: выставление чеков/счетов (חשבונית מס) через сервис вроде Green Invoice / iCount; политика конфиденциальности по израильскому закону о защите данных.
- **FindYpet**: фото, карта и геолокация (Waze/Google Maps), push-уведомления пользователям поблизости.
- **Партнёры**: API/кабинет для ветклиник, зоомагазинов, грумеров и пансионов; интеграция с муниципальным реестром собак (номер чипа).
- **Переводы**: тексты на иврите стоит вычитать носителю языка перед публикацией.
